I build production websites and web applications for education, publishing, B2B export and personal-care clients. Front end is usually Next.js or React; back end is Node.js/PHP with MySQL; WordPress and Elementor cover no-code delivery where that's the better fit for the client. Before web development this was four-plus years of IT infrastructure and systems support, which is why security and reliability tend to show up in how I build things, not just what I build.

Based in Kuala Lumpur, Malaysia. Open to relocation and remote roles, including Ireland.
